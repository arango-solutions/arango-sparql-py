# Plan 07.4-01 Summary — Engine seam 7 (predicate/schema-convention grounding)

Added language-agnostic **seam 7** to the shared `arango_query_core` engine (mirroring the
Phase 07.3 seam-6 entity-grounding pattern) and authored the **NL-ACC-02** requirement it
satisfies. This is the engine-contract layer that all downstream SPARQL-side (Plan 02) and
eval-harness (Plans 03/04) work consumes.

## What was built

**Sibling repo `arango-query-core` (pushed to both remotes):**
- `GroundedPredicate` frozen dataclass (iri/label/kind/domain/range/shape/shape_detail).
- `PredicateIndex` mirroring `LabelIndex` (caller-owned, no memoization, `from_items`/`retrieve`/
  `format_prompt_section`; `""` on no matches).
- Extracted the token-substring ranking into a single module-private `_token_substring_retrieve`
  helper shared by BOTH `LabelIndex.retrieve` and `PredicateIndex.retrieve` (no duplicated scorer).
- Two-tier renderer: terse `domain -> range [kind]` line for every predicate; expanded bracketed
  shape tag + example-triple line only for `value_object`/`category_instance`. Every label passes
  through the existing `_sanitize_label` (prompt-injection mitigation T-07.4-01 — no second sanitizer).
- Seam-7 Protocol members `predicate_index()` / `predicate_prompt_section()` on
  `QueryLanguageAdapter`; enumerated seam list updated (item 7).
- `NLQueryEngine.predicate_k: int = 20` field; `_system_prompt` composes the predicate block
  AFTER the entity block (grammar → few-shot → entities → predicates), post-cache-boundary, never
  in `grammar_prompt_section`.

**This repo `arango-sparql-py`:**
- `NL-ACC-02` authored in REQUIREMENTS.md mirroring NL-ACC-01's acceptance shape (mechanical TBox
  predicate index, CK25 McNemar p<0.05 vs 14/49 grounded baseline, zero regressions, QALD
  directional, W3C ≥96.4%, transpiler untouched) + traceability row + coverage counts
  (Unmapped: 0 preserved).
