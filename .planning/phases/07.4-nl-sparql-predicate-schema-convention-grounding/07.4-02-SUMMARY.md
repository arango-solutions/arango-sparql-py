## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The plan's "Task 1 is harmless against the still-old pin" premise did not hold for `pipeline.py`'s `NLQueryEngine(predicate_k=...)` call**
- **Found during:** Task 1 verification — running `uv run pytest tests/nl2sparql/test_adapter.py tests/nl2sparql/test_pipeline.py -q` against the still-old `c6ae5e1` pin (before touching `pyproject.toml`) produced 11 failures: `TypeError: NLQueryEngine.__init__() got an unexpected keyword argument 'predicate_k'`.
- **Issue:** Unlike the `PredicateIndex` import (which a `TYPE_CHECKING` guard can defer indefinitely since it's type-hint-only), the `NLQueryEngine(predicate_k=self.predicate_k, ...)` call is a genuine runtime call into the sibling package's constructor — `predicate_k` is a real dataclass field only added at the seam-7 SHA (verified by reading the actual pushed `arango_query_core/nl/engine.py` at `~/Desktop/arango-query-core`). No `TYPE_CHECKING` trick can make a runtime keyword argument harmless against an older API.
- **Fix:** Verified the seam-7 SHA's fetchability via `git ls-remote` on both remotes, bumped the pin, ran `uv lock` + `uv sync --all-extras` (restoring dev/service/analyzer/dense extras that a scoped `uv sync --extra nl` had transiently uninstalled), and only then ran the full verification suite for both tasks. Committed the two tasks' file sets in the plan's specified order (adapters+pipeline first as `2ae7960`, pin bump second as `3fc120f`) so git history still preserves the Pitfall-1-required ordering — checking out at the pin-bump commit never finds a non-conformant adapter, and both tasks' own verify commands now pass for real (not nominally) at their respective commits' final on-disk+installed state.
- **Files modified:** none beyond the plan's own file scope (`pyproject.toml`, `uv.lock` for Task 2; no extra files needed).
- **Verification:** `uv run pytest tests/nl2sparql/test_adapter.py tests/nl2sparql/test_pipeline.py -q` → 24 passed; `uv run pytest tests/nl2sparql/ -k "predicate or grounding or adapter" -q` → 34 passed; full `tests/nl2sparql/` suite → 172 passed, 603 skipped; `tests/w3c/test_coverage_gate.py` → 1 passed (non-regression).
