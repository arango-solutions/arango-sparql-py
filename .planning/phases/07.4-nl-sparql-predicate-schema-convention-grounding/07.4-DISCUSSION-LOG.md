## Injection scope (glossary size — dump vs retrieve)

| Option | Description | Selected |
|--------|-------------|----------|
| Retrieve + auto-dump when small | Build the retrieve-relevant-predicates path; dump all when schema is below a size threshold (CK25's ~30). Scales to CDF/DBpedia, lossless on small schemas. | ✓ |
| Always dump full schema | Simplest; breaks on large schemas. | |
| Always retrieve top-k | Uniform path; lossy on tiny schemas where dump is free. | |

**User's choice:** Retrieve + auto-dump when small.
**Notes:** User initially asked for elaboration ("I don't understand"); explained the glossary-size analogy (hand over the whole 30-term glossary vs. only the 10 relevant terms of a 5,000-term one) and the CDF-transfer motivation, then confirmed the recommendation.

| Option | Description | Selected |
|--------|-------------|----------|
