<objective>
Implement seam 7 on BOTH SPARQL adapters and thread it through `NlPipeline`, then bump the
`arango-query-core` pin (both extras) to Plan 01's pushed SHA — as ONE atomic plan.

**Atomicity is the whole point of this plan (Pitfall 1, recurrence risk).** `QueryLanguageAdapter`
is a `@runtime_checkable` Protocol with plain (non-optional) members; the moment the pin makes
seam 7 mandatory, any adapter lacking it fails at attribute-access time. In 07.3-02 the pin was
bumped BEFORE the legacy adapter got seam 6, breaking `test_adapter.py` (fixed a plan later).
Do NOT repeat that. Order within this plan: implement BOTH adapters + pipeline FIRST (harmless
extra methods against the still-old pin), THEN bump the pin — so the adapters are committed no
later than the bump and there is never a non-conformant intermediate state.

Purpose: give the production and legacy SPARQL paths the seam-7 capability and make the new
engine contract live in this repo (D-06/D-07, D-01 mode selection).
Output: both adapters + pipeline conformant; pin bumped in both extras; uv.lock refreshed.
</objective>
