**`paraphrase()` (K=3, human-held-key `OpenAICompatibleClient`) + a pure/offline `slot_preserving` faithfulness guard that rejects filler-dropping and direction-flipping paraphrases; CK25 bank re-emitted with 3 SCRIPTED/PLACEHOLDER paraphrases per example, still offline-validity-gate green.**

## Accomplishments

- Added `paraphrase(question, template, binding, *, k=3, client=None) -> list[str]` to `bank_generator.py`: constructs `OpenAICompatibleClient(provider="openai", model="gpt-4o-mini")` exactly as `runner._client_for` does (function-local import, reads `NL2SPARQL_API_KEY`), with a bounded retry budget (`k*3` attempts) that discards duplicate/unfaithful candidates; degrades to `[]` (never a crash, never a silent live call) when neither a `client` nor `NL2SPARQL_API_KEY` is available.
- Added `slot_preserving(paraphrase, template, binding) -> bool`, the PRIMARY, pure/offline/deterministic D-03 faithfulness guard (zero client/generate calls, mechanically verified via grep): rejects a paraphrase that drops a bound literal filler (`filler_label`/`threshold`) or drops the shape's own `intent_lexicon` entirely, and — for the two ranking shapes (`top_n`/`offset`, both always rendered in descending/"highest" order by this generator) — specifically rejects an opposite-direction superlative (e.g. "cheapest" on a "most expensive" question), catching exactly the intent-flip worked example from the plan.
- Wired both into `generate_bank`/`generate_bank_with_report` via new additive `client=`/`k_paraphrases`-forwarding parameters; each kept example now carries a `paraphrases` list when non-empty.
- Added 4 offline, scripted `test_paraphrase_faithful_*` tests (no key, no network) covering: faithful-accept + slot-dropping-reject + intent-flipping-reject (direct `slot_preserving` calls); `paraphrase()` fed a `ScriptedLLMClient` returning a faithful/unfaithful mix keeps only guard-passing candidates (>=3 survive); the client/key-absent degrade path returns `[]`.
- Re-emitted `vendored/ck25/generated_fewshot_bank.yml` via a new test-local `_EchoParaphraseClient` (deterministic, offline, verbatim-echo-with-rotating-prefix double) — all 77 examples now carry exactly 3 guard-passing SCRIPTED/PLACEHOLDER paraphrases; the file's own `#`-comment header and the test module's docstring both flag this as offline provenance, superseded by Plan 05's real-paraphrase regeneration against the live provider. Re-confirmed `verify_generated_bank.py` exits 0 (paraphrases never touch `query`, so REQ-1/REQ-2 stay unaffected) and the W3C DAWG coverage gate stays green.
