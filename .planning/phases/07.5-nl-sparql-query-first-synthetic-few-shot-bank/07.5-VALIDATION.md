# Phase 07.5 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `07.5-RESEARCH.md` § Validation Architecture. Distinguishes
> always-on **offline CI gates** (no key, no network) from the single
> **human-run credentialed sweep** (the directional adopt/kill measurement).

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (`uv run pytest`); `eval` marker gated by `RUN_EVAL`; `w3c`/`perf` markers separate |
| **Config file** | `pyproject.toml` (`[tool.pytest.ini_options]`) — existing |
| **Quick run command** | `uv run pytest tests/nl2sparql/eval/ -q` (offline; no key, no network) |
| **Offline validity gate** | `uv run python tests/nl2sparql/eval/verify_generated_bank.py` |
| **Full suite command** | `uv run pytest tests/nl2sparql/eval/ -q && uv run pytest tests/w3c/test_coverage_gate.py -q` |
| **Credentialed sweep (human)** | `RUN_EVAL=1 NL2SPARQL_API_KEY=… uv run python tests/nl2sparql/eval/run_generated_sweep.py --sweep` |
| **Estimated runtime** | offline ~10–30s; credentialed sweep several min (human-run, not in CI) |

*Framework install: none — pytest, pyoxigraph, rank_bm25, rdflib, arango_sparql, arango_query_core all present (the Stage-0 spike ran green against them).*

---

## Sampling Rate

- **After every task commit:** `uv run pytest tests/nl2sparql/eval/ -q` + `verify_generated_bank.py` (offline).
- **After every plan wave:** full offline eval suite + `tests/w3c/test_coverage_gate.py` (W3C DAWG ≥ 96.4% non-regression).
- **Phase gate (before adopt/kill):** all offline gates green → then the human-run credentialed directional sweep.
- **Max feedback latency:** ~30s offline (the credentialed sweep is deliberately out of the fast loop — it is the terminal directional measurement, human-run).
