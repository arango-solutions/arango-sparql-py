## Accomplishments
- Ported the spike's substring-token scorer (both-direction label-token matching, hits-desc/shortest-label tiebreak) verbatim into a reusable, pure-Python `LabelIndex` class — zero `pyoxigraph`/`rdflib` imports (packaging boundary held: `grep -c` returns 0).
- Added a generic `format_prompt_section(header=, instruction=, id_prefix=, id_suffix=)` renderer that keeps the engine-side mechanics language-agnostic while leaving exact wording to the adapter (mirrors the `grammar_prompt_section` split).
- Wired `grounding_index()` as seam 6 on `QueryLanguageAdapter`, added `grounding_k: int = 20` to `NLQueryEngine`, and spliced the grounding block into `_system_prompt` AFTER the few-shot section, only when non-empty (mirrors seam 2's exact guard shape).
- Implemented the T-07.3-01 prompt-injection mitigation (`_sanitize_label`): strips C0 control chars/newlines to spaces, collapses whitespace, caps length at 200 chars — proven a no-op on clean labels and proven to collapse a malicious multi-line label to one bullet line.
- 13 new/extended engine-side unit tests (6 in `test_nl_grounding.py`, 1 new + 1 extended-fixture in `test_nl_engine.py`); full arango-query-core suite (90 tests) green.

## Decisions Made
- `LabelIndex` construction stays fully caller-owned (no `lru_cache`-wrapped factory analogous to `cached_few_shot_index`) — grounding data varies per corpus/deployment, so there's no single canonical bank path to memoize on. This matches the plan's explicit instruction (PATTERNS.md "No memoization needed at this layer").
- `GroundedEntity` is a frozen dataclass — an implementation choice for immutability/hashability, not specified by the plan but consistent with its role as an opaque, comparison-by-value record; does not change any observable behavior from the plan's unfrozen reference snippet.
- The new arango-query-core commit (`11b71d5`) stays local and unpushed per the plan's explicit two-repo protocol; Plan 02 verifies both remotes (`ArthurKeen`/`arango-solutions`) reflect it via `git ls-remote` before bumping arango-sparql-py's `pyproject.toml` pin.
