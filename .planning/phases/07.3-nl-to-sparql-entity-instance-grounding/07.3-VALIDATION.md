## Sampling Rate

- **After every task commit:** Run `pytest tests/nl2sparql/ -k grounding -q`
- **After every plan wave:** Run `RUN_EVAL=1 pytest -m eval -q` + `pytest tests/w3c/test_coverage_gate.py -q`
- **Before `/gsd-verify-work`:** Full offline suite green, AND the human-run live CK25 grounded-vs-zero-shot McNemar sweep folded into `baseline.json` (README §5/§7 manual-review discipline)
- **Max feedback latency:** ~30 seconds (offline); live sweep is out-of-band
