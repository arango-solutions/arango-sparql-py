## Pattern Assignments

### `arango_query_core/nl/grounding.py` — add `ClassPathIndex`/`ClassPath` (model, CRUD)

**Analog:** `LabelIndex`/`PredicateIndex` in the same file.

**Frozen, caller-owned constructor pattern** (`grounding.py:162-184`):
```python
class LabelIndex:
    def __init__(self, entities: list[GroundedEntity]) -> None:
        self._entities: list[GroundedEntity] = list(entities)

    @classmethod
    def from_items(cls, items: list[GroundedEntity]) -> LabelIndex:
        return cls(items)

    def retrieve(self, question: str, k: int = 20) -> list[GroundedEntity]:
        return _token_substring_retrieve(self._entities, lambda e: e.labels, question, k)
```
**Deviation required for `ClassPathIndex` (Pitfall 4):** do NOT give it a `retrieve(question, k)` signature. Its retrieval method takes pre-resolved anchor/target identifiers, not a question string:
```python
def shortest_paths(self, anchor_classes: list[str], targets: list[str], k: int = 5) -> list[ClassPath]:
    ...  # BFS depth<=3, global pool across all (anchor,target) pairs, dedupe, sort(len, token-overlap, lexical)
```
Reuse `_sanitize_label`/`_local_name` (`grounding.py:66-94`) for every rendered class/predicate label — same control-char-strip + length-cap discipline already proven against prompt-injection threats (T-07.3-01/T-07.4-01).

**Renderer contract** — `""` on no match (mirrors seam-6/7's `format_prompt_section`): if anchor/target unresolved or no path within depth 3, return empty string. Do not raise.

## Shared Patterns

### Frozen/caller-owned index construction (engine-wide)
**Source:** `arango_query_core/nl/grounding.py:162-184, 249-278`
**Apply to:** `ClassPathIndex` — no file I/O, no memoization inside the class, `.from_items()` classmethod, plain `dict`/`list`/`tuple` internals (no networkx).

### `""`-on-no-match renderer contract
**Source:** `LabelIndex.format_prompt_section`/`PredicateIndex.format_prompt_section` (mirrored by `_sanitize_label`, `grounding.py:66-94`)
**Apply to:** `ClassPathIndex.format_prompt_section` — empty string when anchor/target unresolved or no path found; every rendered label sanitized (control-char strip, length cap).

### Injection-only adapter fields, no production default
**Source:** `grounding_index`/`predicate_index` in both `engine_adapter.py` and `adapter.py`
**Apply to:** `path_index` in both adapters — `self._path_index` set in `__init__`, returned as-is (`None` if never injected), no cached-default fallback.

### Adapter byte-identity discipline
**Source:** `engine_adapter.py:262-345` vs `adapter.py:132-193` (already byte-identical except docstrings)
**Apply to:** every new `path_*` method on both adapters — enforced by the parity test; wording is provisional (D-04) but MUST still match across both adapters at any point in time.

### Composition-point "index-not-None → render → append-if-nonempty"
**Source:** `engine.py:120-139` (seam-6 and seam-7 blocks, identical shape)
**Apply to:** the new seam-8 block in `_system_prompt`, inserted after the seam-7 block.

### Additive eval-config read, gated on `shared_ontology`
**Source:** `runner.py:577-594` (`predicate_grounding:`)
**Apply to:** the new `path_grounding:` read — same `cfg.get(...)`/`k = cfg.get("k", 0)`/build-if-truthy-and-ontology-present shape.

### `NlPipeline` constructor-field-pair threading
**Source:** `pipeline.py:139-163` and `:184-199` (`predicate_k`/`predicate_index`)
**Apply to:** `path_k`/`path_index` — same field-pair-in, field-pair-threaded-into-both-constructions-out shape.
