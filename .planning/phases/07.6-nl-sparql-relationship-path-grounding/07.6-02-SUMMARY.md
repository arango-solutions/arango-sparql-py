- Added seam-8 (`path_index()`/`path_prompt_section()`) to the `QueryLanguageAdapter` Protocol (`seams.py`), mirroring seam-6/7's exact signature shape and docstring convention.

## Decisions Made

- **Target tokens use predicate IRI local names, not labels** — mirrors ClassPathIndex's own edge-naming convention (predicate local names, e.g. `hasManager`) and the established 07.4 rule that the model must never see/emit a human label as a predicate.
- **Reused the private `grounding._local_name` helper** rather than reimplementing IRI-tail extraction — same precedent as 07.4-02's direct access to `PredicateIndex._predicates` (no public accessor exists for either).
- **Retrieval width for anchors/targets is `k=20`** (matching the engine's own `grounding_k`/`predicate_k` defaults), not strict top-1 — per D-02, the real anti-distraction budget is `ClassPathIndex`'s own ≤5 global-pool cap applied downstream in `shortest_paths`.
- **Adapter supplies explicit header/instruction text** to `format_prompt_section` rather than relying on `ClassPathIndex`'s own defaults — keeps wording ownership with the adapter (mirrors seam 6/7's convention), even though the text currently matches the engine module's own default D-04 wording.
